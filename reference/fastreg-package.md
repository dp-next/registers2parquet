# fastreg: Fast Conversion and Querying of Danish Registers with 'Parquet'

Converts large Danish register files ('sas7bdat') into 'Parquet' format
with year-based 'Hive' partitioning and chunked reading for
larger-than-memory files. Supports parallel conversion with a 'targets'
pipeline and reading those registers into 'DuckDB' tables for faster
querying and analyses.
